# Босс 1 · Кукловод — технический контракт и мастер-промпт

Проект: 2D top-down шутер, C++ / SFML 2.5.1
Локация: Городские руины (`city`). Первый из трёх боссов.

Этот лист **не наследует риг солдата** из `SPRITE_SPEC.md`. Шесть типов врагов
сделаны на одном теле перекраской и надстройками — босс, собранный тем же
способом, читается как «толстый рядовой». Кукловод — отдельная фигура,
отдельный кадр, отдельная палитра. Общими остаются только правила проекции:
вид строго сверху, взгляд +X, свободный поворот через `setRotation`.

---

## 1. Закреплённые решения

| Решение | Значение | Почему так |
|---|---|---|
| Кадр | **96 × 96**, пивот **(48, 48)** | тело ~64 px — на треть крупнее врага (64 px кадр, тело ~38 px); поля держат плащ, нити и марионеток |
| Поворот | свободный 360°, `sprite.setRotation()` | как у всех персонажей: один набор кадров |
| Направление | взгляд **вправо (+X)** | 0° = вправо, совпадает с `atan2` — поправок в коде нет |
| Слой оружия | **нет** | босс не держит ствол, контракт хвата на него не распространяется |
| Радиус силуэта | ≤ **48 px** от пивота в каждом кадре | иначе угол вылезет за кадр при повороте |
| Обводка | 1 px по внешнему силуэту | как у остальных персонажей |
| Свет | омни, светлее к центру | направленный «поедет» при повороте |
| Палитра | своя рампа (раздел 6), рампы солдат **не используются** | босс не должен читаться как перекраска врага |
| Миньоны | существующий `enemy_grunt.png` | новых кадров под призыв не нужно |

**Столбцов в строке — 12**, как во всех атласах проекта. Незанятые ячейки
прозрачные. Индекс кадра считается прямо: `{col * 96, row * 96, 96, 96}`.

---

## 2. Кто это и как читается

Высокая сутулая фигура в рваном плаще. Из-под капюшона — треснувшая
фарфоровая маска, единственное светлое пятно в кадре: по нему игрок находит
босса на тёмном полу и понимает, куда тот смотрит. Четыре тонкие руки, из
каждой вниз уходит нить. Вокруг фигуры на нитях висят две-три марионетки
размером с кулак.

Силуэт — рваная звезда: центральная масса плаща плюс четыре тонких выноса рук.
Ни один враг такого контура не имеет (у всех компактный прямоугольник корпуса).
**Чёрная заливка обязана отличаться от любого из шести врагов** — это первая
проверка приёмки.

Ярость меняет силуэт, а не только цвет: маска раскалывается пополам, капюшон
спадает, руки разводятся шире. Игрок должен понять смену фазы, даже если
смотрит на экран боковым зрением.

---

## 3. Якоря — контракт для кода

Вместо контракта хвата (его тут нет) генератор выдаёт покадровые точки,
к которым код цепляет эффекты. Всё в пикселях кадра 96 × 96.

```
пивот              (48.00, 48.00)   центр массы плаща
маска              (60.00, 48.00)   светлое пятно, смещено вперёд по +X
якорь_каста        (72.00, 48.00)   откуда уходит нить в пол при призыве
якорь_нити_1..4    per-frame        концы четырёх рук
```

`якорь_каста` и четыре `якорь_нити` выдаются **на каждый кадр** строк 2 и 3 —
именно оттуда вылетают частицы разлома и облака. Если рука в кадре сдвинулась,
якорь обязан сдвинуться вместе с ней, иначе эффект оторвётся от ладони.

## 4. Раскладка атласа

`boss_puppeteer.png` — **1152 × 672** (12 столбцов × 7 строк по 96 px).

| Строка | Анимация | Кадров | мс/кадр | Луп | Длительность |
|---|---|---|---|---|---|
| 0 | `idle` — висит на месте | 6 | 175 | да | 1.05 с |
| 1 | `glide` — перемещение | 8 | 110 | да | 0.88 с |
| 2 | `summon` — призыв волны | 10 | 110 / 90 / 120 | нет | 1.09 с |
| 3 | `curse` — облако под игроком | 8 | 110 / 80 / 130 | нет | 0.86 с |
| 4 | `hurt` | 3 | 80 | нет | 0.24 с |
| 5 | `death` | 10 | 110 | нет | 1.10 с |
| 6 | `enrage` — раскол маски | 8 | 120 | нет | 0.96 с |

Разнобой в темпе строк 2 и 3 — не прихоть: замах должен тянуться, выброс
щёлкать, возврат провисать. Точные тайминги по кадрам — в разделе 5.

**Эти длительности — контракт с кодом.** Автомат босса держит состояние ровно
столько, сколько идёт строка: замах призыва 0.55 с, окно уязвимости после
выброса 0.36 с. Если генератор меняет число кадров, он меняет и баланс боя —
такие правки согласуются, а не выкатываются молча.

## 5. Раскадровка

### Строка 0 · `idle` (6 кадров, 175 мс, луп)

```
к0  плащ в нижней точке, марионетки провисли на нитях
к1  плащ пошёл вверх, подол отстаёт на четверть цикла
к2  верхняя точка, полы плаща разошлись, маска неподвижна
к3  начало опускания, марионетки догоняют по инерции
к4  подол сходится
к5  возврат к к0, марионетки качнулись в противофазе
```
Маска и капюшон **не дышат**: только плащ, подол и марионетки. Живая, но
устойчивая точка отсчёта — по неподвижной маске игрок читает направление.

### Строка 1 · `glide` (8 кадров, 110 мс, луп)

```
к0  наклон вперёд, подол вытянулся назад
к1-к2  плащ волной, нижняя кромка отрывается от «пола»
к3  марионетки отстают, нити натянуты назад
к4-к5  вторая волна плаща, противофаза первой
к6-к7  затухание, возврат к к0
```
Ног нет: Кукловод скользит. Шага в цикле быть не должно — иначе на медленном
движении появится «пробуксовка».

### Строка 2 · `summon` — призыв волны (10 кадров)

```
к0  110мс  руки пошли вверх, нити провисли — начало замаха
к1  110мс  все четыре руки над головой, марионетки взлетели
к2  110мс  маска наклонилась к полу, нити натянулись в струну
к3  110мс  под фигурой наметился разлом: тонкая светящаяся линия
к4  110мс  пик замаха, свечение разлома на максимуме  ← игрок обязан успеть уйти
к5   90мс  руки вниз рывком, разлом раскрылся
к6   90мс  выброс: из разлома бьёт свет, марионетки сорвались с нитей
к7  120мс  фигура просела, руки висят  ← окно уязвимости
к8  120мс  начало возврата, новые нити тянутся к рукам
к9  120мс  стойка восстановлена, стык с к0 строки 0
```
Кадры к0–к4 (0.55 с) — **телеграф**. Он обязан читаться чёрным силуэтом:
руки над головой + натянутые нити. Кадр к4 — самый широкий силуэт строки.

### Строка 3 · `curse` — облако под игроком (8 кадров)

```
к0  110мс  одна рука выброшена вперёд по +X, три остальные прижаты
к1  110мс  указующая рука вытянулась, нить с неё пошла вперёд
к2  110мс  нить достигла края кадра, на конце набухает капля
к3  110мс  капля сорвалась  ← игрок обязан успеть уйти
к4   80мс  отдача: руку отбросило назад, плащ хлопнул
к5   80мс  вторая волна отдачи, маска дёрнулась
к6  130мс  провис
к7  130мс  возврат в стойку
```
Отличие от строки 2 читается на первом же кадре: там руки **вверх**, тут
одна рука **вперёд**. Два приёма нельзя перепутать по силуэту — это второй
пункт приёмки.

### Строка 4 · `hurt` (3 кадра, 80 мс)

```
к0  корпус отброшен назад, маска дёрнулась вбок
к1  плащ схлопнулся, марионетки мотнулись
к2  возврат
```
Стойку не ломать: попадания частые, длинная реакция превратит босса в куклу.

### Строка 5 · `death` (10 кадров, 110 мс)

```
к0-к1  фигура замерла, все четыре руки повисли
к2-к3  нити рвутся одна за другой, марионетки падают
к4-к5  маска трескается и осыпается — под ней пусто, плащ пустой
к6-к7  плащ оседает на пол, теряя объём
к8-к9  на полу тряпка и осколки маски; последний кадр статичен — это труп
```
Кадр к9 остаётся на полу: код переводит объект в слой трупов. Он обязан
читаться как остатки Кукловода, а не как пятно.

### Строка 6 · `enrage` — раскол маски (8 кадров, 120 мс)

```
к0-к1  фигура выпрямляется, плащ раздувается
к2-к3  трещина через маску, из неё бьёт свет
к4-к5  маска расходится пополам, капюшон спадает
к6-к7  новая стойка: руки разведены шире, нити светятся
```
После этой строки босс возвращается в `idle`/`glide`, но код держит его в
фазе ярости. Чтобы разница была видна и в базовых строках, генератор выдаёт
**вариант палитры «ярость»** (раздел 6) — тем же кадрам меняются только цвета
нитей и свечения, новых кадров не нужно.

## 6. Палитра

Рампы солдат не используются. Свои:

| Роль | Тёмный | Средний | Светлый |
|---|---|---|---|
| Плащ | `#241B2E` | `#3B2D4A` | `#584571` |
| Маска | `#C9C2B4` | `#E8E2D6` | `#FFFDF6` |
| Руки, нити | `#6E6250` | `#9A8B70` | `#C7B695` |
| Марионетки | `#4A3A2B` | `#6B5340` | `#8F7256` |
| Свечение (норма) | `#2E7A4F` | `#49C07C` | `#9CF2C0` |
| Свечение (ярость) | `#7A2E3C` | `#C0495E` | `#F29CAC` |

Зелёное свечение — тот же цвет, которым код рисует облако урона. Если
генератор меняет оттенок, он меняет и константу в игре, иначе эффект и
источник эффекта разъедутся.

## 7. Лист эффектов

`boss_puppeteer_fx.png` — полосами, как `fx.png`, а не общей сеткой.

| Полоса | Кадр | Кадров | Что |
|---|---|---|---|
| `rift` | 64 × 64 | 6 | разлом в полу: раскрытие, вспышка, затухание |
| `cloud` | 96 × 96 | 6 | облако урона: набухает 2 кадра, живёт 2, тает 2 |
| `snap` | 48 × 48 | 4 | обрыв нити, играет на попадании и на смерти |
| `mark` | 64 × 64 | 4 | метка на полу под игроком — куда прилетит облако |

`mark` — не украшение: облако бьёт по площади, и без метки приём читается
как несправедливый. Метка живёт ровно длительность телеграфа строки 3.

Прямоугольники полос — в `boss_puppeteer.json`.

## 8. Приёмка

Проверки те же, что гоняются на всех анимациях проекта, плюс две своих.

1. **Чёрный силуэт против шести врагов.** Залить Кукловода и всех врагов
   одним цветом, поставить в ряд на трёх полах (`#14161B`, `#3A3F4A`,
   `#9AA3B0`). Кукловод обязан опознаваться первым.
2. **Два телеграфа не путаются.** Кадры к0–к4 строки 2 и к0–к3 строки 3,
   залитые чёрным, на масштабе ×1: руки вверх против руки вперёд.
3. **Касание границы кадра** — ни один пиксель не лежит на краю 96 × 96.
4. **Радиус силуэта от пивота** ≤ 48 px в каждом кадре, включая ярость.
5. **Дифф соседних кадров** — нет кадров-дублей; особенно в к6–к7 строки 1.
6. **Стык лупов** — последний кадр строк 0 и 1 сходится с первым.
7. **Читаемость маски** — светлое пятно не теряется ни на одном из трёх полов.

## 9. Что выдать

```
1. boss_puppeteer.png       атлас 1152 × 672 (12 × 7, кадр 96)
2. boss_puppeteer_fx.png    полосы эффектов из раздела 7
3. boss_puppeteer.json      строки, тайминги, пивот, покадровые якоря,
                            прямоугольники полос эффектов
4. превью-лист ×4 с номерами кадров по каждой строке
5. GIF-петли строк 0, 1 и одноразовых 2, 3, 6 в реальном темпе
6. лист чёрных силуэтов: Кукловод + шесть врагов на трёх полах
```

JSON — источник правды для генератора. В игре те же числа продублированы
constexpr-таблицей рядом со `SpriteAtlas.h`: код не читает JSON в рантайме.

## 11. Чего в этом листе нет и не будет

| Нет | Почему |
|---|---|
| `run` | Кукловод не бегает, у него одна скорость скольжения |
| `shoot`, `reload` | оружия нет, стрельбы нет |
| `melee` | в ближний бой не идёт, отступает |
| `roll` | кувырок только у ГГ |
| кадры миньонов | призывает существующих рядовых, `enemy_grunt.png` |
| второй и третий боссы | свои листы, свои силуэты и приёмы; общего рига у боссов нет |
