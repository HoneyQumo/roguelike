# Атлас боеприпасов - Resources/Textures/ammo.png

Полоса из четырёх кадров 32x32, всего 128x32. Нарисовано для проекта, не взято
из сторонних наборов.

| x | Кадр | Рисунок | Где используется |
|---|---|---|---|
| 0 | пистолетный магазин | 10x16, сталь | `ammo_pistol.icon` |
| 32 | винтовочный магазин | 14x21, бакелит | `ammo_rifle.icon` |
| 64 | патроны к дробовику | 12x18, красная гильза с латунью | `ammo_shell.icon` |
| 96 | ракета | 10x17, олива с красной головкой | `ammo_rocket.icon` |

До этого все четыре вида брали один кадр `fx.png 0 288 24 8` - полоску из
анимации пули, поэтому на полу боеприпасы было не различить. Теперь каждый вид
отличается и силуэтом, и цветом: серый короткий, оранжевый высокий изогнутый,
красный сдвоенный, оливковый с головкой.

Рисунок в кадре центрован с запасом по краям. Это не мешает: размер иконки
считается по непрозрачным пикселям (`XYZEngine::OpaqueBounds`), а не по кадру,
поэтому все четыре выходят на пол одной высоты при `scale 0.9`.

Палитра общая на все четыре кадра, контур везде `26 26 30` толщиной 1 px.
