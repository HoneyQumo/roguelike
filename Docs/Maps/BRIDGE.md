# Мост

Длинная локация между тюрьмой и городом: 22 секции по 32 клетки, 704×24 всего. Игрок идёт слева направо и отбивается.

Собирает `Docs/Maps/make_bridge.py`. На выходе - обычные `.config` комнат и акт, которые дальше живут в репозитории как есть: их можно править руками или в mapper, скрипт нужен только чтобы разложить первый вариант.

## Полотно

По вертикали у каждой секции одно и то же:

| строки | что |
|---|---|
| 0-4 | вода |
| 5 | отбойник |
| 6-10 | полоса |
| 11 | разделительная разметка |
| 12-16 | полоса |
| 17 | отбойник |
| 18-23 | вода |

Шаблон рисует поверх этой основы и не трогает крайние колонки - иначе не сойдутся швы между секциями. Торцы моста закрыты отбойником: за первой секцией и за последней ехать некуда.

## Шаблоны секций

| шаблон | что даёт |
|---|---|
| чистый пролёт | редкие машины, покрышки, следы шин - место отдышаться |
| пробка | машины в четыре ряда, масляные пятна |
| блокпост | стена барьеров поперёк с проходом по центру |
| авария | сгоревшие машины, лужи масла, следы торможения |
| топливо | две гряды бочек вдоль полос - место для цепного взрыва |
| пандус | карман за отбойником с тремя ящиками: патроны, аптечка, броня |
| обрушение | половина полотна съедена водой, обойти можно вдоль отбойника |

Порядок задан руками, а не арифметикой по номеру секции: обрушения и пандусы должны попадаться регулярно, иначе половина моста выходит пустой. На 22 секции приходится по четыре пандуса и обрушения, четыре пробки, по три аварии и гряды топлива, два блокпоста.

## Сложность

Врагов становится больше к концу: от одного в начале до пяти в последних секциях. Состав тоже меняется - сначала только мародёры, ближе к середине добавляются штурмовики и щитовики, в конце тяжёлые и радисты.

## Как перебрать карту

```
python Docs/Maps/make_bridge.py
```

Скрипт детерминирован: один и тот же seed даёт одну и ту же карту. Менять раскладку - правкой `SHAPES`, плотность - внутри шаблонов.

Результат проверяется тем же валидатором, что и остальные локации: границы закрыты, выход достижим, вода не режет путь. Проверка идёт в `ShippedLevelsTest`, отдельного запуска не требует.

## Волны

Волны описаны в самом акте, а не в комнатах - это свойство всей локации:

```
[waves]
wave 3 m3 a1
wave 5 m3 a2 s1
```

Строка: пауза перед волной в секундах, дальше группы «символ врага + сколько». Символ здесь из каталога врагов (`m` мародёр, `a` штурмовик, `s` щитовик, `h` тяжёлый, `r` радист), а не из легенды комнаты - у акта своей легенды нет.

Точки появления - клетки `*` в комнатах, по три пары у каждого отбойника в каждой секции. Всего их больше сотни на всю длину моста, и брать их подряд нельзя: волна родилась бы там, куда игрок придёт через минуту. Точка выбирается из **окна вокруг игрока** - дальше `WAVE_SPAWN_GAP` (семь клеток), чтобы враг не вырос под ногами, и ближе `WAVE_SPAWN_REACH` (пятнадцать), чтобы бой случился здесь. Внутри окна точки всё так же перебираются по кругу, иначе волна лезла бы из одной дыры.

### Когда приходит следующая

Волна закрывается двумя способами: рядом с игроком никого не осталось **или** игрок ушёл на `WAVE_ADVANCE_STEP` (56 клеток) от места, где волна его застала.

Второе условие - не поблажка, а необходимость. Мост длинный, и враг, отставший где-то позади, иначе вешал бы погоню навсегда: следующая волна не выходила бы, выход не открывался, локация становилась непроходимой.

По той же причине «живым» считается не всякий уцелевший, а только тот, кто ещё держится в `WAVE_KEEP_RANGE` (24 клетки) от игрока. Отставшие в счёт не идут.

О победе игроку сообщают, только когда из волны действительно никого не осталось. Оторвался - значит оторвался, поздравлять не с чем.

Последняя волна - исключение: пока хоть кто-то дышит в спину, машина не тронется. Убежать от финала нельзя, его надо отбить.

Волн двенадцать - по числу отрезков в `WAVE_ADVANCE_STEP` на 704 клетки моста. Если мост удлинится, тест `TheBridgeHasEnoughWavesForItsLength` напомнит добавить.

## Отбойник и обломки

Стены моста - не обычная кладка: генератор тайлсетов рисует для него кирпичный парапет с металлической балкой поверху. Балка появляется только там, где парапет тянется вдоль - у клетки есть сосед слева или справа. На торцах остаётся голая кладка, иначе отбойник обрывался бы в воздухе.

По краям обрушенных пролётов лежат обломки: куски бетона с торчащей арматурой и крошка вокруг. Это два пропа, `bridge_rubble` и `bridge_rubble_wide`, оба непроходимыми не считаются - обойти дыру по узкой полосе они не мешают.

## Повороты

У пропа два источника угла.

**Из карты** - через `@` в легенде: `C Prop:car_sedan@72` ставит машину поперёк полосы. Так собраны сцены ДТП, где машины сбились в кучу.

**Из каталога** - поле `jitter <градусы>`: небольшой разброс, чтобы брошенные машины не стояли по линейке. Угол берётся из хеша клетки, поэтому одна и та же позиция всегда даёт один и тот же наклон - карта не «дрожит» между запусками.

Оба складываются: машина, поставленная под 72°, всё равно получит свой небольшой доворот.
