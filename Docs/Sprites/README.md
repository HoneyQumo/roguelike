# Спрайт-комплект · что где лежит и как подключить

## Файлы

| Файл | Что это |
|---|---|
| `player.png` | ГГ, 768×1024. Строки 0–7 — анимации, 8–15 — направления кувырка |
| `enemy_grunt/assault/shield/heavy/radio/boss.png` | шесть типов врагов, 768×512. Строки те же 0–7, кувырка нет |
| `weapons.png` | 11 стволов, 480×704. Строка = ствол, столбец = вариант хвата |
| `fx/fx.png` | все эффекты одной текстурой, прямоугольники в `character.json` |
| `fx/hit_flash.frag` | шейдер белой вспышки урона |
| `ui/weapon_icons.png` | иконки стволов для HUD, 104×264, строка = тот же ствол |
| `character.json` | раскладка, тайминги, пивоты, покадровые таблицы |
| `weapons.json` | дульный срез, отдача, размер вспышки по стволам |
| `sfml_example.cpp` | рабочий референс, компилируется и запускается |
| `SPRITE_SPEC.md` | почему всё сделано именно так |

## Три правила, без которых развалится

1. **`texture.setSmooth(false)`** на всех текстурах. Иначе поворот превратит
   пиксель-арт в кашу.
2. **Тело и оружие рисуются в одной позиции с одним углом.** Отличаются только
   `origin`: тело `(32,32)`, оружие `(80,32)`. Никакой тригонометрии для
   крепления ствола к рукам не нужно.
3. **Сцену рендерить в `sf::RenderTexture` нативного размера** и растягивать
   целым множителем. Дробный масштаб делает пиксель неквадратным.

## Как рисовать персонажа

```cpp
float angle = std::atan2(aim.y - pos.y, aim.x - pos.x) * 180.f / 3.14159265f;

body.setTextureRect({frame * 64, row * 64, 64, 64});
body.setOrigin(32.f, 32.f);
body.setPosition(pos);  body.setRotation(angle);  rt.draw(body);

weapon.setTextureRect({variant * 160, weaponRow * 64, 160, 64});
weapon.setOrigin(80.f, 32.f);
weapon.setPosition(pos + rotate(weaponOffset, angle));   // offset из JSON
weapon.setRotation(angle);  rt.draw(weapon);
```

`weapon_offset` в JSON задан **в пикселях кадра**: повернуть на угол прицела
и прибавить к позиции. Так же ставятся вспышка, брызги и предмет в руке.

## Строки атласа тела

| Строка | Анимация | Кадров | мс | Луп |
|---|---|---|---|---|
| 0 | idle | 6 | 175 | да |
| 1 | walk | 8 | 110 | да |
| 2 | run | 8 | 75 | да |
| 3 | shoot | 4 | 60 | нет |
| 4 | reload | 12 | 90 | нет |
| 5 | melee | 6 | 60 | нет |
| 6 | hurt | 3 | 80 | нет |
| 7 | death | 8 | 110 | нет |
| 8–15 | roll, строка = направление | 10 | 50 | нет |

## Кувырок: выбор строки

Направление считается **относительно прицела**, не относительно мира.
Восемь строк так покрывают все направления, и ствол остаётся на цели.

```cpp
float rel = std::atan2(move.y, move.x) - std::atan2(aim.y, aim.x);
int   row = 8 + ((int)std::lround(rel * 4.f / 3.14159265f) % 8 + 8) % 8;
pos += moveDir * dashSpeed * moveSpeed[frame] * dt;   // move_speed из JSON
```

`move_speed` обязателен: без него персонаж поедет на вставании и зависнет
в полёте. `invuln_frames` = `[2..7]` — кадры неуязвимости, крутите под баланс.

## Оружие: столбцы

| Столбец | Когда |
|---|---|
| 0 | обычный хват |
| 1 | без поддерживающей перчатки |
| 2 | без перчатки и без магазина |

Перезарядка переключает столбец по кадрам — таблица `weapon_variant`
в `character.json`. Строки стволов: 0 ak47, 1 m16, 2 shotgun_double,
3 shotgun_pump, 4 smg_suppressed, 5 glock, 6 deagle, 7 pistol_suppressed,
8 knife, 9 bat, 10 rpg. В `weapon_icons.png` тот же порядок строк.

## Эффекты в fx.png

Прямоугольник каждой группы лежит в `character.json` → `atlas.fx.rects`.
Кадр `i` группы: `{x + w*i, y, w, h}`.

| Группа | Кадров | Как ставить |
|---|---|---|
| `muzzle_flash` | 3 | в `muzzle_offset` из weapons.json, поворот на угол прицела, размер × `flash_scale` |
| `bullet` | 3 | 0 винтовочный, 1 пистолетный, 2 дробь. Поворот на угол полёта |
| `impact` | 4 | искры в стену, поворот на угол нормали поверхности |
| `explosion` | 7 | взрыв РПГ, поворот не нужен |
| `blood_pool` | 10 | **под телом**, тот же пивот и угол, что у трупа |
| `blood_hit` | 4 | брызги, поворот на угол урона, спавнить 1–2 с разбросом ±20° |
| `blood_speck` | 1 | декаль на полу |
| `shell_fly` | 4 | гильза крутится |
| `rocket` | 2 | ракета в полёте |
| `hand_item` | 6 | магазины/гильза/ракета в руке: `mag_rifle, mag_smg, mag_pistol, shell, rocket, stowed` |
| `pickup` | 6 | пары «обычный / подсвеченный»: аптечка, патроны, броня. **Поворот не применять** |

## Порядок отрисовки

```
blood_pool → body → weapon → hand_item → muzzle_flash → blood_hit
```

## Вспышка урона

```cpp
hit.setUniform("texture", sf::Shader::CurrentTexture);
hit.setUniform("amount", flash);        // 1.0 в момент попадания
rt.draw(body, &hit);  rt.draw(weapon, &hit);
flash = std::max(0.f, flash - dt / 0.12f);
```

Шейдером, а не кадрами: вспышка нужна поверх любого кадра любой анимации.

## Смерть

Четыре флага из JSON: после `drop_frame` (=1) заспавнить ствол объектом
на полу — спрайт тот же из `weapons.png`. С кадра 3 запустить лужу
(свой таймер 150 мс, продолжает расти после конца анимации). В конце
`hold_last_frame` — перестать обновлять кадр, и `freeze_rotation` — заморозить
угол, иначе труп будет доворачиваться за прицелом.

## Враги

Два разных рычага:

* **Перекраска** — шесть значений цвета корпуса и рукавов, `recolor_slots`
  в JSON. Ноль новых кадров, тот же атлас.
* **Силуэтная надстройка** — ранец, баллоны, антенна, щит, ширина плеч.
  Меняет контур, поэтому у каждого типа своя текстура.

Кувырок только у ГГ.

## Собрать демо

```
g++ -std=c++17 sfml_example.cpp -o demo -lsfml-graphics -lsfml-window -lsfml-system
```

Запускать из папки, где лежит `assets/`. WASD движение, мышь прицел,
ЛКМ огонь, Space кувырок, R перезарядка, F удар, 1–9 смена ствола, K смерть.

Константы раскладки в примере продублированы намеренно — он не тащит
json-библиотеку. В боевом коде читайте `character.json`.
