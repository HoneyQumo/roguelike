# Формат уровня

Локация - это текстовый `.config`. Пересобирать игру после правки не нужно: файлы читаются при запуске.

Комментарии начинаются с `;`, пустые строки игнорируются. Файл - UTF-8.

Уровень бывает двух видов:

- **одна карта** - файл из этой папки, описан ниже
- **акт** - карта, собранная из комнат `Resources/Rooms`, см. [раздел про акт](#акт-из-комнат)

## Реестр

`levels.config` задаёт порядок прохождения: локации идут так, как записаны в файле.

```
[level bridge]
title Мост
act Resources/Acts/act1_bridge.config
```

| ключ | что |
|---|---|
| `title` | название на экране загрузки |
| `file` | путь к карте-одиночке |
| `act` | путь к акту из комнат |

`file` и `act` взаимоисключающи.

## Секции карты

Порядок секций в файле произвольный, но `[map]` обычно последняя - она самая длинная.

### `[level]`

```
[level]
title Арена
next catacombs
boss colossus 3.0 1.8
```

| ключ | аргументы | что |
|---|---|---|
| `title` | текст до конца строки | название локации |
| `next` | id локации | куда ведёт выход; по умолчанию следующая в реестре |
| `kind` | слово | пометка вида карты, используется комнатами акта |
| `tileset` | имя | набор тайлов: `ruins` (по умолчанию), `prison`, `bridge`, `street`, `catacombs` |
| `music` | имя | фоновая музыка |
| `ambient` | имя | фоновый шум |
| `boss` | `<id> [health] [damage] [drop]` | босс локации |

У `boss` первым идёт id из каталога боссов (`puppeteer`, `gravedigger`, `colossus`). Множители здоровья и урона необязательны и по умолчанию равны 1; оба обязаны быть больше нуля. Последним - id предмета, который выпадет с боссом.

Босс появится только там, где на карте стоит клетка `BossSpawn`.

### `[legend]`

Одна строка - один символ карты:

```
[legend]
# Wall
. Floor
g GruntSpawn
p Item:potion_small
```

Символ - первый знак строки, дальше через пробел его значение.

Символ, которого нет в легенде, не ломает загрузку: клетка станет пустотой, а в лог уйдёт предупреждение. Пробел - пустота по умолчанию, о нём не предупреждают.

**Тайлы:**

| имя | что |
|---|---|
| `Floor` | пол |
| `Wall` | стена |
| `Empty` | пустота; по краю ямы сама ставится стена |
| `Water` | вода: непроходима, рисуется, по краю ставится стена |
| `Line` | дорожная разметка, проходима |
| `PlayerSpawn` | где стоит игрок, если пришёл не через вход |
| `Entrance` | вход; главнее `PlayerSpawn` |
| `Exit` | выход с локации |
| `WaveSpawn` | точка появления волн и погони, для всего прочего обычный пол |
| `Breach` | край пролома; кладётся в `[overlay]` поверх воды |

**Враги** - имя из каталога, клетка под ними считается полом:

`GruntSpawn`, `MarauderSpawn`, `AssaultSpawn`, `ShieldSpawn`, `HeavySpawn`, `RadioSpawn`, `BossSpawn`

**Составные значения** - через префикс с двоеточием:

| префикс | пример | что |
|---|---|---|
| `Item:` | `Item:potion_small` | предмет из `Resources/Items/items.config` |
| `Prop:` | `Prop:car_sedan` | объект из `Resources/Props/props.config` |
| `Prop:` с `@` | `Prop:car_sedan@72` | то же, повёрнутое на 72° |
| `Door:` | `Door:door_exit` | дверь; тем же id её открывает ключ |
| `Zone:` | `Zone:hall` | область комнаты: враги в ней спят, пока игрок не войдёт |
| `Patrol:` | `Patrol:gate` | точка маршрута; ближайший враг подхватит маршрут |
| `Watch:` | `Watch:gate` | точка того же маршрута, где караульный осматривается |
| `Switch:` | `Switch:power` | рубильник |
| `Hatch:` | `Hatch:drain` | люк |
| `Escape:` | `Escape:city_car` | машина побега |

Машина побега сама служит переходом на следующую локацию, тайл `>` рядом с ней не нужен. На уровне с `[pursuit]` машина появляется не сразу: она приезжает, когда игрок подходит к её месту.

Точки одного маршрута обходятся в том порядке, в каком объявлены в легенде. Имя маршрута должно быть своим у каждого поста: общее имя склеит далёкие точки в один обход.

### `[map]`

Строки из символов легенды. Ширина карты - по самой длинной строке; равнять остальные под неё необязательно, короткая строка просто кончается раньше.

Левый верхний угол - начало координат карты; в мире ось Y смотрит вверх, поэтому нижняя строка файла окажется внизу экрана.

### `[overlay]`

Верхний слой: вторая карта символов поверх первой. Нужен там, где одной клетки мало - дыра в мосту, под которой видно воду, копоть от взрыва, разметка на асфальте.

```
[map]
~~~~~~
..RR..
......

[overlay]

  --

```

Пробел - ничего не рисуем. Символы те же, что и в `[map]`, из той же легенды.

Три правила, о которых стоит помнить:

- **слой только рисует.** Проходимость, коллизии и пути строятся по нижнему слою. Стена в накладке не остановит, вода не утопит
- **предметы и двери сюда не кладутся.** `Item:`, `Door:` и прочие составные значения в накладке игнорируются - иначе один символ означал бы разное в зависимости от того, в какую карту попал
- **разметка наверху берётся из своей строки атласа** - без куска асфальта под собой, поэтому ложится на любое покрытие

`Breach` - особый случай: кадр выбирается по маске соседей, как у стен. Клетка сама смотрит, с каких сторон к ней примыкает дорога, и рисует обрыв бетона именно с них. На карте ставится один символ, шестнадцать вариантов помнит движок. Класть его надо поверх воды - иначе край повиснет над асфальтом.

Строки можно не равнять: короткая просто кончается раньше. Слоя может не быть вовсе - тогда секцию не пишут.

Комнаты акта несут накладку вместе с собой: она поворачивается и отражается вместе с комнатой.

### `[waves]`

Оборона на месте: игрок отбивает волны, пока выход заперт.

```
[waves]
wave 3 g3 a1
wave 5 a2 s1
```

Строка: `wave <пауза в секундах> <символ><сколько> ...`. Символы берутся **из легенды этой карты** и обязаны быть врагами. Следующая волна ждёт, пока кончится предыдущая.

Врагам нужны клетки `WaveSpawn`, иначе волнам неоткуда выйти.

### `[pursuit]`

Погоня: за игроком постоянно идут, отбиться насовсем нельзя. Для беговых локаций вроде моста.

```
[pursuit]
keep 6
grow 12
respawn 2.5

from 0.0  m4 g3
from 0.5  a4 s2 m2
```

| ключ | что |
|---|---|
| `keep` | сколько преследователей держится на хвосте |
| `grow` | до скольки растёт, если игрок стоит на месте |
| `respawn` | через сколько секунд приходит замена убитому |
| `from` | `<доля пути 0..1> <символ><вес> ...` - кто выбегает на этом отрезке |

Кто именно выбежит, решает жребий по весам. Отрезки обязаны идти по возрастанию доли - иначе файл будет отвергнут.

Здесь символы берутся **из каталога врагов** (`g`, `m`, `a`, `s`, `h`, `r`), а не из легенды карты: погоня описывается и на уровне акта, где своей легенды нет.

Погоня разворачивает всех расставленных на карте врагов лицом к входу - заслону незачем стоять спиной к бегущему.

Обе секции независимы: карта может нести и волны, и погоню.

## Акт из комнат

Длинная локация собирается из готовых комнат `Resources/Rooms`.

```
[act]
title Мост
next street
tileset bridge
music march

[library]
bridge_01 Resources/Rooms/act1_bridge_01.config

[pursuit]
keep 6
...

[rooms]
bridge_01 0 0
bridge_02 32 0 turn 1 mirror
```

| секция | что |
|---|---|
| `[act]` | то же, что `[level]`, но без `boss` и `ambient` |
| `[library]` | `<имя> <путь>` - какие комнаты доступны |
| `[rooms]` | `<имя> <колонка> <строка> [turn N] [mirror]` - куда поставить |

`turn N` поворачивает комнату на N четвертей по часовой, `mirror` отражает. Сборщик проверяет швы: соседние комнаты должны стыковаться проходами.

Секции `[waves]` и `[pursuit]` у акта общие на всю локацию. Легенды у акта нет - её несёт каждая комната.

## Проверка

Все локации из реестра проверяются тестами (`ShippedLevelsTest`): границы закрыты, выход достижим, вода не режет путь, у босса есть клетка. Отдельного запуска не нужно - достаточно прогнать `EngineTest`.
