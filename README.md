# Roguelike

Top-down роглайк на C++17 и SFML. Собирается в Visual Studio 2022 под x64.

## Сборка и запуск

Открыть `Roguelike.sln` в Visual Studio 2022 и собрать конфигурацию `Debug` или `Release`, платформа `x64`.

Из консоли:

```
msbuild Roguelike.sln /p:Configuration=Release /p:Platform=x64
```

Игра ложится в `Roguelike/x64/<конфигурация>/Roguelike.exe`, ресурсы копируются рядом при сборке.

## Тесты

```
x64\Release\EngineTest.exe
```

Тесты запускаются из корня репозитория и работают без окна. Часть из них читает настоящие файлы карт, поэтому ловит опечатки в данных, а не только ошибки в коде.

## Где лежит контент

| Папка | Что там |
|---|---|
| `Roguelike/Resources/Levels` | реестр локаций `levels.config` и карты целиком |
| `Roguelike/Resources/Rooms` | комнаты, из которых собираются акты |
| `Roguelike/Resources/Acts` | раскладка комнат по сетке |
| `Roguelike/Resources/Items` | предметы |
| `Roguelike/Resources/Props` | объекты на карте |
| `Roguelike/Resources/Loot` | таблицы выпадения |
| `Roguelike/Resources/Textures` | тайлсеты и атласы |

Порядок прохождения - порядок блоков в `levels.config`. Новая локация добавляется блоком, пересобирать игру не нужно.

## Редактор карт

Карты удобнее рисовать и проверять в отдельном редакторе: [HoneyQumo/roguelike-mapper](https://github.com/HoneyQumo/roguelike-mapper).

Открыть онлайн: https://honeyqumo.github.io/roguelike-mapper/

Что он умеет:

- рисовать комнату кистью, с настоящими тайлами и объектами;
- складывать комнаты в локацию и показывать её целиком, без границ комнат;
- отдавать готовый текст `.config` и открывать существующие файлы;
- на лету проверять связность, границы, порядок ключей и стыки комнат.

Чтобы открыть то, что уже есть: в редакторе нажать «Выбрать файлы» и указать файлы из `Roguelike/Resources/Rooms` и нужный акт из `Roguelike/Resources/Acts`.

Редактор берёт палитру и тайлы из этого репозитория. После правки каталогов их надо перегнать - команда описана в его README.
