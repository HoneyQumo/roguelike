# Катсцены

Сцена - это последовательность «битов»: у каждого имя действия и длительность. `CutsceneTimeline` знает только про порядок и время, `CutscenePlayerComponent` крутит таймлайн и дёргает обработчики, зарегистрированные снаружи по имени действия.

Ядро ничего не знает ни про машины, ни про камеру, ни про затемнение - это и позволяет переиспользовать его для входа в локацию, гибели или финала акта.

## Как собрать сцену

```cpp
auto scene = object->AddComponent<CutscenePlayerComponent>();
scene->SetBeats({{"board", 0.8f}, {"drive", 6.5f}, {"leave", 1.4f}});

scene->SubscribeBeatStarted([](const std::string& beat) { /* что сделать один раз на входе в бит */ });
scene->SetHandler("drive", [](float deltaTime) { /* что делать каждый кадр этого бита */ });
scene->SubscribeFinished([]() { /* сцена кончилась */ });

scene->Play();
```

## Команды

Кроме имени и длительности бит несёт **команду** - то, что делается один раз при входе в него:

| команда | что |
|---|---|
| `TakeControl` | забрать у игрока управление |
| `GiveControl` | вернуть |
| `LookAtTarget` | увести камеру к объекту по имени |
| `LookAtPoint` | увести камеру в точку |
| `LookAtHero` | вернуть камеру к игроку |

У команд камеры есть `travel` - за сколько секунд доехать. Камера едет с мягким разгоном и торможением: линейный проезд читается как рывок.

```cpp
CutsceneBeat away;
away.command = CutsceneCommand::LookAtTarget;
away.target = "Hatch_drain";
away.travel = 0.55f;
away.seconds = 1.65f;          // сколько держать кадр после приезда
```

Камеру и замок управления сцена получает снаружи:

```cpp
scene->SetCamera(camera);
scene->SetControlLock([this](bool isTaken) { SetControlTaken(isTaken); });
scene->SetTargetFinder([](const std::string& name) { return GameWorld::Instance()->FindGameObject(name); });
```

Так проигрыватель не тянет за собой ни камеру, ни игрока и остаётся проверяемым.

## Управление возвращается само

Две вещи, на которых игра встала бы намертво:

- **сцена забыла отдать управление** - по её окончании оно возвращается в любом случае
- **сцену оборвали** смертью игрока или сменой локации - `Stop()` возвращает и управление, и камеру

Забрать управление дважды нельзя: второй `TakeControl` ничего не делает, иначе вернуть его потом было бы нечем.

Возвращается ровно то, что забрали: `SetControlTaken` помнит список выключенных компонентов. Слепо включить всё обратно нельзя - часть могла быть выключена не сценой.

## Камера

Камера живёт **отдельным объектом**, а не компонентом игрока. Пока она висела на игроке, увести её к люку было нечем.

`CameraDirectorComponent` держит её за игроком, пока сцена не скажет иначе. `Release()` возвращает мгновенно - на случай, когда сцену оборвали и разводить красоту уже некогда.

## Сцена с люком

Рычаг открывает люк где-то в стороне, и без камеры игрок видит только то, что дёрнул рычаг. Сцена показывает результат: камера уезжает к люку, ждёт, пока он откроется, и возвращается.

Собирается в три бита: забрать управление, уехать к люку и подождать, вернуться. Все подписки делает `DeveloperLevel::SubscribeLevers` - для каждого рычага, у которого есть свой люк.

Два разных крючка не случайны: `SubscribeBeatStarted` срабатывает один раз при входе в бит - включить затемнение, показать текст. `SetHandler` зовётся каждый кадр, пока бит идёт - двигать машину, вести камеру.

Один длинный кадр может перескочить несколько коротких битов сразу; таймлайн это переживает и доходит до нужного.

## Побег с моста

Сцена из трёх битов:

| бит | сколько | что происходит |
|---|---|---|
| `board` | 0.8 с | у игрока отбирают управление, в HUD «Гони!» |
| `drive` | 6.5 с | машина разгоняется вправо, игрок едет вместе с ней |
| `leave` | 1.4 с | экран гаснет, машина всё ещё едет |

Игрок на время сцены становится пассажиром: все его компоненты выключаются, кроме трансформа, камеры и привязки HUD, а позиция каждый кадр берётся от машины. Камера висит на игроке, поэтому едет сама - отдельной работы с камерой не понадобилось.

По окончании сцены начинается следующая локация.

Машина заперта, пока идут волны: иначе в неё можно было бы сесть на старте и проскочить весь мост.
