# Атлас дверей - Resources/Textures/doors.png

Полоса из двух кадров 64x64, всего 128x64. Основа - CC0-набор Kenney
"Top-down Shooter" (`Docs/Sprites/vendor/README.md`), тайл в столбце 9, строке 16
листа `Tilesheet/tilesheet_complete.png`.

| x | Кадр | Где используется |
|---|---|---|
| 0 | створка с замком | закрытая дверь, `DOOR_LOCKED_TEXTURE` |
| 64 | створка без замка | открытая дверь, `DOOR_OPEN_TEXTURE` |

Замок дорисован поверх исходного тайла: стальная накладка 28x12 по центру
створки и латунная скважина. Дерево створки взято у Kenney без перекраски - три
тона (175;120;62), (196;134;71), (154;105;55) уже совпадают с палитрой ящиков.

Створка занимает всю высоту кадра и стоит по центру по ширине, поэтому опорная
точка спрайта `(0.5, 1.0)` попадает ровно на её нижний торец - это и есть петля.
Кадр рисуется один и тот же для любой ориентации двери: направление задаёт
поворот, `DoorHinge::closedAngle`. Арт смотрит вверх при повороте 0, а движок
считает 0 направлением вправо, отсюда `LeafAngleFor` вычитает 90 градусов.

Второго кадра для распахнутой створки нет - дверь открывается поворотом на
`DOOR_SWING_ANGLE` вокруг петли за `DOOR_SWING_TIME`, а кадр меняется только
чтобы убрать замок.

Если `doors.png` не загрузился, `CreateDoor` рисует клетку прямоугольником
`DOOR_LOCKED_COLOR` и не поворачивает ничего - как было до появления атласа.
