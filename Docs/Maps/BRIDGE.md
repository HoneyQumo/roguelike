# Мост

Длинная локация между тюрьмой и городом: 22 секции по 32 клетки, 704×24 всего. Игрок идёт слева направо и отбивается.

Собирает `Docs/Maps/make_bridge.py`. На выходе - обычные `.config` комнат и акт, которые дальше живут в репозитории как есть: их можно править руками или в mapper, скрипт нужен только чтобы разложить первый вариант.

## Полотно

По вертикали у каждой секции одно и то же:

| строки | что |
|---|---|
| 0-4 | вода |
| 5 | отбойник |
| 6-10 | полоса |
| 11 | разделительная разметка |
| 12-16 | полоса |
| 17 | отбойник |
| 18-23 | вода |

Шаблон рисует поверх этой основы и не трогает крайние колонки - иначе не сойдутся швы между секциями. Торцы моста закрыты отбойником: за первой секцией и за последней ехать некуда.

## Шаблоны секций

| шаблон | что даёт |
|---|---|
| чистый пролёт | редкие машины, покрышки, следы шин - место отдышаться |
| пробка | машины в четыре ряда, масляные пятна |
| блокпост | стена барьеров поперёк с проходом по центру |
| авария | сгоревшие машины, лужи масла, следы торможения |
| топливо | две гряды бочек вдоль полос - место для цепного взрыва |
| пандус | карман за отбойником с тремя ящиками: патроны, аптечка, броня |
| обрушение | половина полотна съедена водой, обойти можно вдоль отбойника |

Порядок задан руками, а не арифметикой по номеру секции: обрушения и пандусы должны попадаться регулярно, иначе половина моста выходит пустой. На 22 секции приходится по четыре пандуса и обрушения, четыре пробки, по три аварии и гряды топлива, два блокпоста.

## Сложность

Врагов становится больше к концу: от одного в начале до пяти в последних секциях. Состав тоже меняется - сначала только мародёры, ближе к середине добавляются штурмовики и щитовики, в конце тяжёлые и радисты.

## Как перебрать карту

```
python Docs/Maps/make_bridge.py
```

Скрипт детерминирован: один и тот же seed даёт одну и ту же карту. Менять раскладку - правкой `SHAPES`, плотность - внутри шаблонов.

Результат проверяется тем же валидатором, что и остальные локации: границы закрыты, выход достижим, вода не режет путь. Проверка идёт в `ShippedLevelsTest`, отдельного запуска не требует.
