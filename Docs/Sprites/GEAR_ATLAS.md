# Снаряжение - Resources/Textures/gear.png

Кадр 32x32, пока один. Нарисовано для проекта.

| x | Кадр | Рисунок | Где используется |
|---|---|---|---|
| 0 | бронепластина | 12x16, сталь со скруглённым низом | `armor_plate.icon` |

Пластина даёт `effect AddArmor 5`. Броня в игре - плоское вычитание из урона
(`HealthComponent::CalculateDamage`), потолок `PLAYER_ARMOR_CAP = 20`, стартовое
значение у игрока 5. На потолке пластина не применяется и остаётся лежать: её
подбор возвращает `false`, игрок видит уведомление и может вернуться за ней
позже.

Лист заведён отдельно от `ammo.png`, чтобы снаряжение не смешивалось с
боеприпасами; новые предметы такого рода добавляются сюда следующими кадрами.
